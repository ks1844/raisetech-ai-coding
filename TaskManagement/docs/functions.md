# 機能一覧

---

## 1. 機能要件

### 1.1 ボード機能

| 機能 | 説明 |
|------|------|
| ボード一覧表示 | 作成済みのボードを一覧で表示する |
| ボード作成 | 名前を入力してボードを新規作成する |
| ボード削除 | ボードを削除する（配下のカラム・カードも削除） |
| ボード名変更 | ボード名をインラインで編集する |

### 1.2 カラム機能

| 機能 | 説明 |
|------|------|
| カラム表示 | ボード内のカラムを横並びで表示する |
| カラム作成 | 名前を入力してカラムを新規作成する |
| カラム削除 | カラムを削除する（配下のカードも削除） |
| カラム名変更 | カラム名をインラインで編集する |

### 1.3 カード機能

| 機能 | 説明 |
|------|------|
| カード表示 | カラム内のカードを縦に並べて表示する |
| カード作成 | タイトルを入力してカードを新規作成する |
| カード削除 | カードを削除する |
| カード編集 | タイトル・説明・期限日を編集する |
| Drag & Drop | カードをドラッグしてカラム間・カラム内で並び替える |

### 1.4 カードの持つ情報

| フィールド | 必須 | 説明 |
|-----------|------|------|
| タイトル | ○ | タスクの名前 |
| 説明・メモ | - | タスクの詳細や補足 |
| 期限日 | - | タスクの完了期限 |

## 2. 非機能要件

### 2.1 動作環境

| 項目 | 内容 |
|------|------|
| 対応ブラウザ | Chrome / Firefox / Safari 最新版 |
| 対応OS | Windows 10以降 / macOS 12以降 |
| 推奨画面解像度 | 1280×720 以上（PC表示のみ。スマートフォン・タブレット対応は対象外） |

### 2.2 データ・永続化

| 項目 | 内容 |
|------|------|
| 保存方式 | ブラウザの localStorage（サーバー不要） |
| データ上限 | localStorageの仕様上、概ね5MB程度が上限。通常利用では問題なし |
| データ消失リスク | ブラウザのキャッシュ・サイトデータをクリアするとデータが消える |
| データ形式 | JSON |

### 2.3 パフォーマンス

| 項目 | 目標値 | 備考 |
|------|--------|------|
| 初回表示 | 3秒以内 | 通常のPC環境・有線またはWi-Fi接続を想定 |
| 操作レスポンス | 即時（体感遅延なし） | D&D・編集・保存等の操作 |
| データ読み書き | 50ms以内 | localStorageへのアクセス |

### 2.4 保守性・コード品質

| 項目 | 内容 |
|------|------|
| 型安全 | TypeScriptの型定義を徹底し、`any`の使用を禁止する |
| コンポーネント設計 | 責務を明確に分割し、1コンポーネント1責務を原則とする |
| コーディング規約 | ESLint / Prettier の設定に従う |

### 2.5 セキュリティ

| 項目 | 内容 |
|------|------|
| XSS対策 | Reactの標準的なレンダリング（JSX）を使用し、`dangerouslySetInnerHTML`は使用しない |
| 外部通信 | 本アプリはサーバー通信を行わないため、APIキー・認証情報の管理は不要 |

## 3. ユースケース

### UC-01：ボードを作成する

| 項目 | 内容 |
|------|------|
| アクター | ユーザー |
| 事前条件 | ボード一覧画面を表示している |
| 基本フロー | 1. 「ボードを作成」ボタンをクリックする<br>2. ボード名を入力する<br>3. 作成ボタンを押す<br>4. 一覧に新しいボードが追加される |
| 代替フロー | ボード名が未入力の場合、作成できない（バリデーションエラー表示） |

### UC-02：カードを別のカラムへ移動する

| 項目 | 内容 |
|------|------|
| アクター | ユーザー |
| 事前条件 | ボード詳細画面を表示しており、カードが1枚以上存在する |
| 基本フロー | 1. 移動したいカードをドラッグする<br>2. 移動先のカラムへドロップする<br>3. カードが移動先カラムに表示される<br>4. localStorageのデータが更新される |
| 代替フロー | ドロップをキャンセル（元の位置に戻る） |

### UC-03：カードを編集する

| 項目 | 内容 |
|------|------|
| アクター | ユーザー |
| 事前条件 | ボード詳細画面を表示しており、カードが1枚以上存在する |
| 基本フロー | 1. カードをクリックする<br>2. 編集モーダルが開く<br>3. タイトル・説明・期限日を編集する<br>4. 保存ボタンを押す<br>5. モーダルが閉じ、カードに変更が反映される |
| 代替フロー | キャンセルボタンを押すと変更が破棄されてモーダルが閉じる |

### UC-04：ボードを削除する

| 項目 | 内容 |
|------|------|
| アクター | ユーザー |
| 事前条件 | ボード一覧画面を表示している |
| 基本フロー | 1. 削除対象ボードの削除ボタンをクリックする<br>2. 確認ダイアログが表示される<br>3. 「削除する」を選択する<br>4. ボードと配下のカラム・カードがすべて削除される |
| 代替フロー | 「キャンセル」を選択するとボードは削除されない |
