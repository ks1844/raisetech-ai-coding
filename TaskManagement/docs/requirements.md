# 要件定義書

## 1. プロジェクト概要

| 項目 | 内容 |
|------|------|
| プロジェクト名 | Trello風タスク管理アプリ |
| 目的 | 個人の学習・タスクをカンバン形式で視覚的に管理する |
| 対象ユーザー | 自分一人（シングルユーザー） |
| 認証 | 不要 |

---

## 2. 用語定義

| 用語 | 説明 |
|------|------|
| ボード | タスクを管理する作業スペース。複数作成可能 |
| カラム | ボード内のカラム（例：ToDo / In Progress / Done） |
| カード | カラム内の個々のタスク |

---

## 3. 機能要件

### 3.1 ボード機能

| 機能 | 説明 |
|------|------|
| ボード一覧表示 | 作成済みのボードを一覧で表示する |
| ボード作成 | 名前を入力してボードを新規作成する |
| ボード削除 | ボードを削除する（配下のカラム・カードも削除） |
| ボード名変更 | ボード名をインラインで編集する |

### 3.2 カラム機能

| 機能 | 説明 |
|------|------|
| カラム表示 | ボード内のカラムを横並びで表示する |
| カラム作成 | 名前を入力してカラムを新規作成する |
| カラム削除 | カラムを削除する（配下のカードも削除） |
| カラム名変更 | カラム名をインラインで編集する |

### 3.3 カード機能

| 機能 | 説明 |
|------|------|
| カード表示 | カラム内のカードを縦に並べて表示する |
| カード作成 | タイトルを入力してカードを新規作成する |
| カード削除 | カードを削除する |
| カード編集 | タイトル・説明・期限日を編集する |
| Drag & Drop | カードをドラッグしてカラム間・カラム内で並び替える |

### 3.4 カードの持つ情報

| フィールド | 必須 | 説明 |
|-----------|------|------|
| タイトル | ○ | タスクの名前 |
| 説明・メモ | - | タスクの詳細や補足 |
| 期限日 | - | タスクの完了期限 |

---

## 4. データ定義

アプリのデータはすべて localStorage に JSON 形式で保存する。

### 4.1 データ構造の全体像

```
localStorage
└── "boards"  ←キー名
    └── Board[]  ←ボードの配列
        └── Board
            ├── id
            ├── title
            └── columns: Column[]
                └── Column
                    ├── id
                    ├── title
                    └── cards: Card[]
                        └── Card
                            ├── id
                            ├── title
                            ├── description
                            └── dueDate
```

### 4.2 Board（ボード）

| フィールド名 | 型 | 必須 | 説明 |
|------------|-----|------|------|
| id | string | ○ | ボードを一意に識別するID（例：`board-1`） |
| title | string | ○ | ボード名（例：「学習タスク」） |
| columns | Column[] | ○ | このボードに属するカラムの配列（初期値は空配列） |

### 4.3 Column（カラム）

| フィールド名 | 型 | 必須 | 説明 |
|------------|-----|------|------|
| id | string | ○ | カラムを一意に識別するID（例：`column-1`） |
| title | string | ○ | カラム名（例：「ToDo」「進行中」「完了」） |
| cards | Card[] | ○ | このカラムに属するカードの配列（初期値は空配列） |

### 4.4 Card（カード）

| フィールド名 | 型 | 必須 | 説明 |
|------------|-----|------|------|
| id | string | ○ | カードを一意に識別するID（例：`card-1`） |
| title | string | ○ | カードのタイトル（例：「Next.jsの勉強」） |
| description | string | - | カードの説明・メモ。未入力の場合は空文字 `""` |
| dueDate | string | - | 期限日。`YYYY-MM-DD` 形式（例：`"2026-06-30"`）。未設定の場合は `null` |

### 4.5 保存データの例

```json
[
  {
    "id": "board-1",
    "title": "学習タスク",
    "columns": [
      {
        "id": "column-1",
        "title": "ToDo",
        "cards": [
          {
            "id": "card-1",
            "title": "Next.jsの勉強",
            "description": "App Routerの基礎から始める",
            "dueDate": "2026-06-30"
          }
        ]
      },
      {
        "id": "column-2",
        "title": "進行中",
        "cards": []
      },
      {
        "id": "column-3",
        "title": "完了",
        "cards": []
      }
    ]
  }
]
```

## 5. 非機能要件

| 項目 | 内容 |
|------|------|
| データ保存 | ブラウザの localStorage に保存（サーバー不要） |
| 対応環境 | モダンブラウザ（Chrome / Firefox / Safari 最新版） |
| レスポンシブ | スマートフォン対応は対象外（PC表示のみ） |

---

## 6. 対象外（スコープ外）

- ユーザー認証・ログイン機能
- 複数ユーザーでの共有・権限管理
- カードへのファイル添付
- 通知・リマインダー機能
- 検索・フィルター機能

---

## 7. 画面一覧

| 画面名 | 説明 |
|--------|------|
| ボード一覧画面 | アプリのトップ。ボードを一覧表示し、選択・作成できる |
| ボード詳細画面 | 選択したボードのカラムとカードを表示・操作できる |
| カード編集モーダル | カードをクリックして詳細（説明・期限日）を編集する |
