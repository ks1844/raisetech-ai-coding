# 要件定義書

---

## 1. プロジェクト概要

| 項目 | 内容 |
|------|------|
| プロジェクト名 | Trello風タスク管理アプリ |
| 目的 | RaiseTech AIコーディングコースの学習成果物として、フロントエンド開発の基礎技術を習得する |
| 学習目標 | Next.js / TypeScript / Tailwind CSS を用いたSPAの設計・実装を実践する |
| 対象ユーザー | 自分一人（シングルユーザー） |
| 認証 | 不要 |

### 背景・課題

| 課題 | 内容 |
|------|------|
| 学習課題 | コースで学んだ技術を実際のアプリ開発に落とし込む場が必要 |
| テーマ選定理由 | カンバンボードはCRUD・状態管理・D&Dなどフロントエンドの頻出パターンを網羅しており、学習効果が高い |

---

## 2. 用語定義

| 用語 | 説明 |
|------|------|
| ボード | タスクを管理する作業スペース。複数作成可能 |
| カラム | ボード内のカラム（例：ToDo / In Progress / Done） |
| カード | カラム内の個々のタスク |
| D&D | ドラッグアンドドロップ。カードをマウスで掴んで移動する操作 |
