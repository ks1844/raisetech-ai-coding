## 4. 採用理由・補足

| 技術 | 採用理由 |
|------|---------|
| Vite + React | モダンなフロントエンド開発。高速なビルドと HMR（ホットモジュールリプレースメント）を実現 |
| Spring Boot | バックエンド実装用フレームワーク。REST API の構築と DB 操作を効率化 |
| TypeScript | 型安全なコードを書く習慣を身につける。`any`の使用は禁止 |
| Tailwind CSS | ユーティリティクラスによる効率的なスタイリングを学ぶ |
| @hello-pangea/dnd | react-beautiful-dndのメンテナンス継続フォーク。D&D実装の学習に使用 |
| PostgreSQL | リレーショナルデータベース。ボード・カラム・カード情報を永続化 |
| Flyway | DB マイグレーション管理。スキーマ変更を安全に管理 |
