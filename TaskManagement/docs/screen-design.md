# 画面一覧

---

## 1. 画面構成と遷移

```
[ボード一覧画面]
    │
    ├─ ボードをクリック
    │
    ▼
[ボード詳細画面]
    │
    ├─ カードをクリック
    │
    ▼
[カード編集モーダル]（ボード詳細画面上に重ねて表示）
```

---

## 2. ボード一覧画面

| 項目 | 仕様 |
|------|------|
| 表示内容 | 作成済みボードをカード形式で一覧表示 |
| ボード作成 | 画面上部に「ボードを作成」ボタンを設置。クリックでボード名入力フォームを表示 |
| ボード選択 | ボードカードをクリックするとボード詳細画面へ遷移 |
| ボード名変更 | ボード名をクリックするとインライン編集が可能になる |
| ボード削除 | ボードカードに削除ボタンを設置。クリックで確認ダイアログを表示し、確認後に削除 |
| ボードが0件の場合 | 「ボードがありません。作成してください。」などの空状態メッセージを表示 |

---

## 3. ボード詳細画面

| 項目 | 仕様 |
|------|------|
| 表示内容 | ボード名（ヘッダー）＋カラムを横並びで表示 |
| カラム追加 | カラム列の右端に「＋カラムを追加」ボタンを設置 |
| カラム削除 | 各カラムのヘッダーに削除ボタンを設置 |
| カラム名変更 | カラム名をクリックするとインライン編集が可能になる |
| カード追加 | 各カラムの下部に「＋カードを追加」ボタンを設置 |
| カード削除 | 各カードに削除ボタンを設置 |
| D&D | カードをドラッグしてカラム間またはカラム内で並び替えができる |
| 一覧へ戻る | ヘッダーに「一覧へ戻る」リンクを設置 |

---

## 4. カード編集モーダル

| 項目 | 仕様 |
|------|------|
| 表示トリガー | カードをクリックで開く |
| 編集項目 | タイトル（テキスト入力）・説明（テキストエリア）・期限日（日付ピッカー） |
| バリデーション | タイトルは必須。未入力の場合は保存不可 |
| 保存 | 「保存」ボタンで変更を確定し、モーダルを閉じる |
| キャンセル | 「キャンセル」ボタンまたはモーダル外クリックで変更を破棄して閉じる |
